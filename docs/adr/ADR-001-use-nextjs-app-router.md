ADR-001: Use Next.js App Router

Status

Accepted

Context

The project requires a modern React framework capable of server-side rendering, routing, server actions, and long-term scalability.

Decision

Use Next.js with the App Router architecture.

Consequences

Positive

- Modern React architecture
- Built-in routing
- Server rendering support
- Excellent developer experience
- Strong ecosystem

Negative

- Higher framework complexity
- Major versions may introduce breaking changes
